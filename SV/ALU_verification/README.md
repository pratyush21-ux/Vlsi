# SystemVerilog ALU Verification Framework

A class-based SystemVerilog verification framework for an ALU (package, interface, DUT instance and covergroup), run in QuestaSim.

## Coverage results (QuestaSim 2024.1)

| Metric | Result |
|---|---|
| Covergroup coverage | **100 percent** (all 73 bins) |
| Toggle coverage (interface and DUT) | **100 percent** |
| Statement coverage | about 95 percent |
| Branch coverage | 90 to 94 percent |
| Filtered total coverage | 89.49 percent |

Condition coverage in the package is 50 percent, a known gap listed as a candidate for more directed tests.

**Tools:** SystemVerilog, QuestaSim, vcover.
