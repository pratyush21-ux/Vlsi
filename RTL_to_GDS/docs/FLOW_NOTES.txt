---------------------------------------------------------------------
STEP 0 : DESIGN SPEC (what we are building)
---------------------------------------------------------------------
  * 16-bit data, 16-bit instructions, 12-bit address (4K words)
  * 8 registers RA..RH, RH is the link register for JAL
  * Pipeline: IF -> ID -> EX -> MA -> WB
  * One single-port memory for code AND data (von Neumann)
      - structural hazard: LOAD/STORE in MA stalls IF and ID
  * RAW hazards: ID stalls until the source register is written back
    (no forwarding)
  * Branches resolve in EX; no fetch while a jump is in ID/EX
  * Top-level pins: clk, rst, mem_addr[11:0], mem_rdata[15:0],
                    mem_wdata[15:0], mem_we, dbg_pc[11:0]
  * The memory is OUTSIDE the chip -> the GDS is only the CPU core.

Timing constraints  flow\constraints\simple_cpu_v4.sdc
  create_clock clk  period 20 ns (50 MHz), uncertainty 0.25 ns
  input / output delay 4 ns (20 % of the period used outside the chip)
  driving cell inv_2 on inputs, 33 fF load on outputs
  max transition 0.75 ns, max fanout 10

STEP 2 : LOGIC SYNTHESIS  (RTL -> gate-level netlist)     [first try done]
---------------------------------------------------------------------
Why: turn behavioural Verilog into real standard cells of the PDK
     (NAND, NOR, MUX, flip-flops ...) so it can be placed and routed.

Script flow\02_synth.tcl  (yosys -c 02_synth.tcl)
  read_liberty -lib <tt_025C_1v80.lib>   -> know cell pins
  read_verilog -sv RTL/Simplecpu.v
  synth -top simple_cpu_v4 -flatten      -> generic gates + FFs
  dfflibmap -liberty ...                 -> map FFs to sky130 FF cells
  abc -D 20000 -dont_use sky130_fd_sc_hd__lpflow_* -liberty ...
                                         -> map logic to sky130 cells,
                                            target 20000 ps = 20 ns
  setundef / splitnets / opt_clean       -> clean netlist for OpenROAD
  hilomap                                -> tie-hi / tie-lo cells
  insbuf                                 -> "assign a=b" -> real buffer
  check / stat / write_verilog           -> results\02_synth\simple_cpu_v4.v

Issues found and fixed in the first try:
  1) "Wire mem_addr[..] is used but has no driver" warnings
     -> false alarm: Yosys did not know the sky130 cell pin directions.
        Fix: read_liberty -lib at the start.  Now "0 problems".
  2) ABC picked sky130_fd_sc_hd__lpflow_* cells (power-gating isolation
     cells, not meant for normal logic).

STEP 5 : POWER DISTRIBUTION NETWORK  (OpenROAD pdngen)         [DONE]
---------------------------------------------------------------------
Why: every cell needs VPWR (1.8 V) and VGND. Build a low-resistance
     metal grid from the chip pins down to each cell.

Script flow\05_pdn.tcl
  create nets VPWR (POWER) / VGND (GROUND)
  add_global_connection  VPWR <- pins VPWR, VPB   VGND <- pins VGND, VNB
  set_voltage_domain -name CORE -power VPWR -ground VGND
  define_pdn_grid -name core -pins {met4 met5}   (grid = block power pins)
  add_pdn_ring   met4/met5, width 1.6, spacing 1.7, 6 um from the core
  add_pdn_stripe met1 0.48 um -followpins     rails on every cell row
  add_pdn_stripe met4 1.6 um, pitch 50 um     vertical straps
  add_pdn_stripe met5 1.6 um, pitch 50 um     horizontal straps
  add_pdn_connect met1<->met4, met4<->met5    via stacks
  pdngen ; check_power_grid -net VPWR / VGND

STEP 6 : PLACEMENT  (OpenROAD gpl + resizer + dpl)             [DONE]
---------------------------------------------------------------------
Why: give every cell an (x,y) position so that wires are short and
     timing is met, then fix electrical rules (slew/cap/fanout).

Script flow\06_place.tcl

  place_pins -hor_layers met3 -ver_layers met2   59 IO pins on die edge,
                                                  near the cells they feed
  global_placement -density 0.55 -timing_driven  final global placement
  estimate_parasitics -placement            wire RC from placed positions
  set_dont_use clkdlybuf*/dlygate*/dlymetal*  (delay cells kept for hold)
  buffer_ports -buffer_cell buf_4           buffer every IO port
  repair_design -slew_margin 20 -cap_margin 20   fix slew / cap / fanout
  repair_tie_fanout conb_1/HI , conb_1/LO   one tie cell per few loads
  detailed_placement                        legalise: cells on rows/sites
  optimize_mirroring                        flip cells to shorten wires
  check_placement -verbose

STEP 7 : CLOCK TREE SYNTHESIS  (OpenROAD TritonCTS)            [DONE]
---------------------------------------------------------------------
Why: one clk pin cannot drive 322 flip-flops. Build a balanced tree of
     clock buffers so the clock edge arrives at every FF at ~ the same
     time (low skew). Then fix hold, which only shows up with a real
     clock (clock now arrives LATE at some FFs).

Script flow\07_cts.tcl
  clock_tree_synthesis -root_buf clkbuf_16
        -buf_list {clkbuf_2 clkbuf_4 clkbuf_8}
        -sink_clustering_enable -sink_clustering_size 10
        -sink_clustering_max_diameter 50
  set_propagated_clock [all_clocks]      real clock delays from now on
  repair_clock_nets ; detailed_placement
  report_cts ; report_clock_skew
  repair_timing -setup -setup_margin 0.2
  repair_timing -hold  -hold_margin 0.1  (0.1 ns safety for routing)
  detailed_placement ; check_placement
