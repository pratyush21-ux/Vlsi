# Arithmetic and Accelerator Designs

Multiplier-free and approximate arithmetic engines for DSP, edge AI and photonic reservoir computing. These are **description-only entries**: results and architecture are documented, the source code is available on request (see each project).

| Project | Highlight |
|---|---|
| [DAVIC](DAVIC) | Folded, pipelined distributed-arithmetic inner-product engine: **9x fewer LUTs, 5.8x lower power** than a parallel baseline |
| [Fixed_Weight_DA_MAC](Fixed_Weight_DA_MAC) | Multiplier-free fixed-weight DA MAC on a **Red Pitaya (Zynq-7010)** for a photonic reservoir computer, AXI-Stream and DMA weight loading |
| [RIDGE_Approx_DA_MAC](RIDGE_Approx_DA_MAC) | Parameterizable MAC with **run-time precision** and **compile-time approximate adder tree** (LOA / LOAWA / truncation) |
| [Booth_Multipliers](Booth_Multipliers) | Classical, radix-4, radix-8 and **hybrid radix-4/8 approximate Booth** multipliers: **58 percent lower PDP, 60 percent smaller area** |
