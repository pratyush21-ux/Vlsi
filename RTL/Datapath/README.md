# Datapath Building Blocks

Small datapath and bus designs. Description-only entries, code available on request.

| Project | Description |
|---|---|
| [Mini_CPU](Mini_CPU) | 8-bit mini CPU with control unit, ALU and register datapath |
| [FFT_Butterfly](FFT_Butterfly) | Radix-2 FFT butterfly with complex multiply |
| [Tri_State_Bus](Tri_State_Bus) | 32-bit shared bus with tri-state buffers, 4 sources |
