# Single-Bus Architecture with Tri-State Buffers

A 32-bit shared bus driven by four sources through **tri-state buffers**. A decoder enables exactly one driver at a time while the others stay in high impedance, the standard way to build a single-bus datapath without multiplexers.

- 4-channel 32-bit input
- Decoder-controlled bus selection
- High-impedance inactive drivers
- Testbench included (code on request)

**Tools:** Verilog, Icarus Verilog.
