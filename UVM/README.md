# UVM Verification Projects

UVM (Universal Verification Methodology) verification environments in SystemVerilog, run in QuestaSim.

| Project | Description |
|---|---|
| [FW_ALU](FW_ALU) | Complete UVM testbench for a 32-bit RISC-V style ALU: sequence, driver, monitor, agent, scoreboard, functional coverage. Results, architecture diagram and screenshots are in the project README |
| [FW_FIFO](FW_FIFO) | UVM verification of a synchronous FIFO with queue reference model and SVA. 100 percent functional, code and assertion coverage |
| [FW_Zeroriscy_ALU](FW_Zeroriscy_ALU) | Coverage-driven UVM testbench for the PULP zero-riscy ALU. 100 percent functional and code coverage, 0 mismatches |
| [FW_decoder](FW_decoder) | Placeholder folder for a decoder verification project (README and code not added yet) |

The full UVM source code is kept private. See the README in each project folder for results and how to request code access.

See also [`../SV`](../SV) for plain SystemVerilog (non-UVM) verification projects.
